도꼭지 마케팅 도우미

공식 홍보처를 조사하고 기존 연락과 답장을 확인하여, 도꼭지 홈페이지로 연결되는 제휴 문의를 관리하는 독립 프로그램입니다.

이용 대상

운영자가 승인한 단일 Gmail 계정으로 사용합니다. 고객 예약을 접수하거나 일반 고객의 Google 로그인을 받는 서비스가 아닙니다. 앱의 Google 운영 상태 전환은 검색 노출이나 Google의 추천·보증을 의미하지 않습니다.

주요 기능

  • 매일 한국시간 오후 2시 기존 제휴 문의의 새 답장 확인
  • 잠실·송파 지역 모임 등 적합한 공식 홍보처 검색
  • 공식 페이지 연락처 및 제휴 안내 검증, Gmail·로컬 기록 중복 확인
  • 확인된 신규 연락처에 하루 최대 3건 제휴 문의, 공식 홈페이지 추적 링크 포함
  • 운영자에게 새 답장·오류 등 확인이 필요한 사항 알림

권한과 이용 조건

Gmail 조회·전송을 위해 운영자가 Google 동의 화면에서 권한을 승인해야 합니다. 개인정보처리방침에 데이터 접근·저장·전달·삭제 방법을 설명합니다. 공개 페이지를 방문하는 것만으로 Gmail 접근이 허용되지는 않습니다.

운영자는 발송 계정과 연락 목적에 대한 정당한 권한을 보유해야 하며, 수신 거부·연락 중지 요청을 반영해야 합니다. 이 프로그램을 사칭, 회원 위장, 무단 대량 발송 또는 허위 혜택 홍보에 사용하지 않습니다. 새 답장은 운영자가 검토하며 비용·계약·할인·좌석 보장에 대한 결정을 자동으로 수락하지 않습니다.

실행 환경과 한계

현재 Windows PC의 작업 스케줄러로 실행하며, PC 전원·사용자 로그인·인터넷·유효한 API 인증이 필요합니다. Mac 이전 시 환경 설치와 재인증 및 스케줄 등록이 필요합니다. Google 인증 만료, API 한도, 외부 페이지 변경이나 네트워크 오류로 작업이 중단될 수 있습니다. 검색 결과와 자동 검증은 오류가 있을 수 있으며 노출·방문·예약 증가를 보장하지 않습니다.

적합한 연락처가 없으면 발송하지 않습니다. 전송 결과가 불명확하면 자동 재전송하지 않습니다. Google 접근 권한 철회 또는 로컬 작업 중지로 자동 실행을 멈출 수 있습니다. 프로그램 사용에 따른 API 비용은 연결된 계정의 요금·크레딧 조건을 따르며, 별도 유료 충전은 운영자가 결정합니다.
